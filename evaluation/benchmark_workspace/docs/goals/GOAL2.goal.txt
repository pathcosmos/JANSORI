## 규칙
- test 결과로 설정을 고르거나 문항에 맞춰 프롬프트를 조정하지 않는다

- 사용자 확인 필요: git commit/push, HF 업로드·모델 카드 수정, ../llm-traditional 수정·삭제, 외부 게시
